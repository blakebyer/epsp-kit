# fEPSP
1. Run the following commands from the package root `src/evoked`.
    
    From the CLI (recommended):
    ```bash
    poetry run evoked-analyze --data data/ --output . --config recipes/fepsp/fepsp.yml
    ```
    __OR__

    Using the Python API:
    ```bash
    poetry run python recipes/fepsp/fepsp.py
    ```
