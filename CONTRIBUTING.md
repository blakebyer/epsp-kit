# Contributing to evoked
Thank you in advance for your contribution!

## Ways to help
1. Open an [issue](https://github.com/blakebyer/evoked/issues/new/choose)
2. Open a [pull request](https://github.com/blakebyer/evoked/compare)
3. Send an email to [blake@blakebyer.com](mailto:blake@blakebyer.com)

## Code of conduct
Harrassment or discrimination is not tolerated. Project maintainers have the right and responsibility to reject and/or ban contributions from those who do not abide by this code of conduct.

## AI usage
AI usage is allowed so long as you cite which agent you used (e.g., Claude, ChatGPT, Gemini, etc.) in your request and the output is human-verified. Portions of this package were developed with assistance from Claude and ChatGPT, so we will not hold contributors to a different standard. However, large breaking/structural or nonsensical changes proposed by agents are disallowed.
